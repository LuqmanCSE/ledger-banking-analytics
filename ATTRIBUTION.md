# Attribution

The original prototype was informed by Aadya Agarwal's [retail-banking-sql-powerbi](https://github.com/aadyaa04/retail-banking-sql-powerbi). This release generates all client and transaction rows independently through `scripts/prepare_data.py`. The release package contains the generator, synthetic rows, and their checksum audit.

The interface draws visual inspiration from the [shadcn Morgan Stanley design study](https://www.shadcn.io/design/morgan-stanley). Ledger is an independent portfolio project with fictional banking activity.

Apache ECharts uses Apache-2.0. zrender includes its BSD license, and esbuild uses MIT. The build bundles their notices at `/notices.txt`.
