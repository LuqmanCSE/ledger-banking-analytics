Metric definitions

Consistent language for every report

Client balance

Initial deposit plus all recorded signed transactions. Includes negative balances.

Monthly active clients

Distinct customers with at least one transaction in the selected calendar month.

Activity retention

Clients active in both months divided by prior-month active clients. Blank without a valid prior denominator.

Inactive clients

180+ days since last transaction, measured at the latest recorded activity date. Not confirmed churn.

Use Ledger in Power BI Desktop

  1. Open the baseline report.

    For a project ZIP, extract it and open Ledger.pbip in Power BI Desktop. Keep the report and semantic model folders alongside it. For a .pbix download, open the file directly.

  2. Refresh and save an editable file.

    In the project, choose Home → Refresh to load the synthetic snapshot. Check the client count, then use File → Save as and select Power BI Desktop file (.pbix).

  3. Connect the transaction data separately.

    Choose Get data → Blank query → Advanced Editor and paste the downloaded Power Query script. Set BaseUrl to the local Ledger server or your public deployment.
